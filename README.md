# Aditya Mehta — Personal Portfolio

A modern, high-performance portfolio website for **Aditya Mehta** (Data Analyst & Business Intelligence Specialist), designed with a dark luxury aesthetic, rich orange and amber neon accents, and server-side Python architecture.

## 🚀 Key Features

- **Pure HTML, CSS & Server-Side Python**: Zero client-side JavaScript lag or memory overhead.
- **Hardware-Accelerated Background Animation**: Seamless 24 FPS continuous full-screen ambient video background compiled from 240 high-definition frames.
- **Bespoke 3D Isometric Visuals**: Custom 3D representations for Sales Analytics, Event Operations, and AI/LLM Technical Presentations.
- **Dynamic Python Backend**:
  - Multithreaded HTTP server (`ThreadingHTTPServer`)
  - Server-side template engine dynamically calculating and rendering Pune (IST) time
  - Optimized MIME headers and video streaming support
- **Modern Responsive Design System**:
  - Technical Skills & Competencies (2×2 layout)
  - Verified Professional Certifications
  - Capabilities & Direct Inquiry channels

---

## 🛠️ Tech Stack

- **Backend**: Python 3 (Standard Library: `http.server`, `socketserver`, `datetime`, `zoneinfo`)
- **Frontend**: Semantic HTML5 & Vanilla CSS3
- **Media**: Optimized H.264 MP4 (`yuv420p` with `faststart`)

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/adityamehta1979-sketch/Aditya-Mehta.git
   cd Aditya-Mehta
   ```

2. **Start the local server**:
   ```bash
   python app.py
   ```

3. **Open in browser**:
   Navigate to [http://localhost:8000/](http://localhost:8000/)
